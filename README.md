# Komentář k zákonu č. 189/1999 Sb., o nouzových zásobách ropy, o řešení stavů ropné nouze a o změně některých souvisejících zákonů (zákon o nouzových zásobách ropy)

Otevřený komentář k zákonu o nouzových zásobách ropy — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; vytváření a udržování nouzových a specifických zásob, skladování a ochraňovatelé, stav ropné nouze a opatření k omezení spotřeby, použití zásob, informační povinnost, kontrola, působnost Správy státních hmotných rezerv a přestupky.

Konsolidované znění: dokument e-Sbírky `SB-1999-00189_2024-01-01`.
